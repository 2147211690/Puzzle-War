# Puzzle War - 抖音拼图小游戏

一个基于Unity开发的抖音平台拼图小游戏，支持多种道具、关卡系统和广告变现。

## 项目简介

Puzzle War是一款休闲益智类拼图游戏，专为抖音平台打造。游戏通过滑动拼图块来完成图片拼合，提供多种道具帮助玩家解决难题，并集成了完整的广告变现系统。

## 主要特性

- 🧩 **多样化拼图玩法**：支持不同尺寸和难度的拼图关卡
- 🔨 **道具系统**：锤子和剪刀道具帮助玩家突破难关
- 🎯 **关卡系统**：多关卡设计，难度递进
- 💰 **广告变现**：集成激励广告、插屏广告和Banner广告
- 📱 **抖音平台集成**：支持侧边栏入口、用户数据同步
- 🎵 **音效系统**：背景音乐和音效管理
- 💾 **进度保存**：本地保存玩家进度和道具数量
- 🎨 **精美UI**：流畅的动画效果和用户界面

## 技术栈

### 开发环境
- **Unity**: 游戏引擎
- **C# 10+**: 编程语言
- **.NET 6.0+**: 目标框架

### 核心插件
- **抖音SDK (TTSDK)**: 平台接口集成
- **DOTween**: 动画效果

### 设计模式
- **状态机模式**: 游戏状态管理
- **MVC架构**: 代码组织结构
- **单例模式**: 全局管理器

## 游戏玩法

### 基本操作
1. **滑动拼图**：点击拼图块，如果相邻有空位，拼图块会移动到空位
2. **完成拼图**：将所有拼图块移动到正确位置完成游戏
3. **使用道具**：在困难时可以使用道具帮助完成拼图

### 道具说明
- **🔨 锤子**：可以消除任意一个拼图块
- **✂️ 剪刀**：可以剪断障碍物

### 游戏状态
- **主页状态**：显示主菜单和关卡选择
- **游戏状态**：进行拼图游戏
- **胜利状态**：显示胜利界面和奖励
- **道具状态**：使用道具的特殊状态

### 抖音平台发布
1. 使用抖音开发者工具导入构建文件
2. 测试游戏功能
3. 提交审核
